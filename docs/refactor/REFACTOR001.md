# 改善要項

本ドキュメントでは,実装したMODやシステムの改善についてまとめる

## 観点

実施済みの改善施策の見直しと,他の改善施策の検討を行う

### コーディング

- コードの可読性
- コードの冗長性撤廃
- コードの保守性向上
- コードの再利用性向上
- コードの拡張性向上
- コードのパフォーマンス向上

### ゲームシステム

- ゲームの難易度向上施策
  - プレイヤーにとってのゲーム体験向上施策
    - プレイヤーに性的攻撃を受けることを促すメリット
      - [SPEC005](/docs/spec/SPEC005.md)の実装
    - プレイヤーに性的攻撃を受けることを促すデメリット
      - [SPEC002](/docs/spec/SPEC002.md), [SPEC003](/docs/spec/SPEC003.md)の実装
  - エネミーオブジェクトのルール変更
    - 進行に時間をかけると敵がスポーンする
      - 画面外
      - 画面外かつ背後
