# SPEC004: 敵のランダム出現および追加配置による難易度向上

## 要件定義

- エリア毎に対応した敵のランダム出現と追加配置を行い,ゲームの難易度を向上させる
- そのエリアをロードする際に,そのエリアに対応した敵のランダムで追加配置する
  - 可能であれば,そのエリアで停滞しているプレイヤーに対してペナルティを与えるために,画面外で敵をスポーンさせる
  - 可能であれば,奇襲を行うために, プレイヤーの背後に敵をスポーンさせる
- ゲーム内には,落下物や罠などのオブジェクトがある
  - 可能であれば,これもエリア毎に追加配置したい
  - 可能であれば,宝箱の配置をランダムにしたい
