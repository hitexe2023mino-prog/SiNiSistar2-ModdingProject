# プレイ統計画面

## 目的

本機能では[SPEC001.md](./SPEC001.md)の`funscript GUI`のようなWeb GUIを用いて,
アクターの統計情報を閲覧できるようにすることを目的とする.

## 要件

- プレイしているセーブデータのいくつかの統計情報を閲覧できること
  - [SPEC003.md](./SPEC003.md)で追加された`堕落(Corruption)`の統計情報を閲覧できる
  - 絶頂回数が閲覧できること
  - 最も絶頂させた回数が多いアクターの名前が表示されること
- デザインは中世ファンタジーの日記帳をモチーフにすること
- デバフを受けた回数が表示されること
  - デバフの種類ごとに回数が表示されること
- 可能であれば,リアルタイムで統計情報が更新されること
  - ページを開きながらプレイする可能性があるため
- 統計情報は揮発せず,セーブデータに保存されること
